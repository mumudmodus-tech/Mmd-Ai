# 🚀 Mmd-Ai : Mobile-First AI Web Generator

Aplikasi web berbasis AI yang dirancang khusus untuk pengguna *smartphone* (Mobile-Optimized) guna membantu membuat draf konten, skrip, dan e-book profesional secara instan dengan format siap unduh (*PDF Layout*).

---

## ✨ Fitur Utama
- **⚡ Mobile-First & Responsive:** Ringan, cepat, dan dioptimalkan untuk diakses langsung lewat HP.
- **📘 Multi AI Skills:** 
  - Penyusunan Bab E-Book Terstruktur
  - Skrip Iklan & Affiliate (Hook Tajam)
  - Konten & Konsep Media Sosial
  - Draf Email Marketing Penjualan
- **📥 Auto-PDF Layout Engine:** Dilengkapi fitur konversi otomatis teks hasil AI menjadi file PDF berformat rapi siap jual (cocok untuk platform digital seperti Lynk.id).
- **🔄 Smart Auto-Retry:** Sistem penanganan jaringan otomatis jika server sedang padat.
- **🔒 Local API Security:** API Key disimpan secara lokal di browser perangkat Anda untuk menjaga privasi dan keamanan.

---

## 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, Tailwind CSS
- **AI Engine:** Google Gemini API (`gemini-3.8-flash`)
- **PDF Library:** `html2pdf.js`
- **Hosting & CMS:** Vercel & GitHub

---

## 💡 Cara Penggunaan
1. Buka aplikasi web app Mmd-Ai.
2. Masukkan **Gemini API Key** Anda pada kolom yang tersedia.
3. Pilih kategori *AI Skill* yang diinginkan (misal: E-Book).
4. Tulis ide atau topik simpel Anda (contoh: *"Panduan praktis cuan dari HP untuk pemula"*).
5. Klik **Generate** dan unduh hasilnya dalam bentuk **PDF** untuk langsung dibagikan atau dijual!
